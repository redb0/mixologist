# Административный frontend Mixologist

React/TypeScript SPA для управления ингредиентами.

```bash
npm install
npm run dev
```

Vite открывает интерфейс на `http://localhost:5173` и проксирует `/api` на
backend `http://localhost:8080`.

Проверки:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
